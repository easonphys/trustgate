# 竞品一页纸（v0）

| 对象 | 关系 | 差异 |
|------|------|------|
| **AIP** | 协议近亲 / 可对齐 | 我们交付可运行 proxy + 产品化治理路径；先把 MCP 生产闸门做厚 |
| **KYA-OS** | 标准层灵感（DID/VC） | v0.1 用更轻的 Ed25519+scope 链，后续可映射 VC |
| **OpenA2A AIM** | 身份管理重叠 | 我们强调**衰减委托链**与 MCP 热路径代理 |
| **Arcade** | 互补 | 他们偏动作执行与工具目录；我们偏权威与证据 |
| **Portkey / 模型网关** | 非竞争 | 管模型路由；不管 Agent→Agent 委托收窄 |
| **企业 IdP (Okta 等)** | 互补 | 管人；不管 Agent 委托图 |

**打法：** 做 IdP 不愿做、网关做不深的中间层——Agent 委托的 TLS/OAuth。
