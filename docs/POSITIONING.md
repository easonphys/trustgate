# TrustGate 定位（1 页）

## 我们是什么

TrustGate 是 Agent 的**信任层**：为 MCP 工具调用与 A2A 委托提供可验证身份、**只能收窄的权限委托**、以及可审计证据。

我们不是 Agent 框架，不是多模型网关，不是沙箱。

## 一句话

> IdP 证明「人是谁」；TrustGate 证明「Agent 被允许做什么、委托如何收窄、做过什么」。

## 为什么是现在

- MCP/A2A 正在成为默认互联协议，但大量工具端点仍无认证。
- 企业卡点从「Agent 能不能跑」变成「越权与责任如何证明」。
- 开源协议刚成型，商业控制面尚未被巨头锁死。

## 产品形态

| 层 | 内容 | 收费 |
|----|------|------|
| 开源内核 | 签发/校验、衰减委托、MCP proxy、审计事件 | 免费 Apache-2.0 |
| Team / Enterprise | 注册表、策略包、SSO、SIEM、VPC | 订阅 / 年合同 |
